# ADR-0007: 将持久学习记忆拆为证据层与画像层

**Status:** `accepted`
**Date:** `2026-10-20`
**Deciders:** `产品所有者（本人）`

## Context

Deriva 当前的 system prompt 是静态教学约束，上下文组装只读取当前主对话及其祖先链。用户需要一个新的全局学习记忆入口，使 Deriva 能跨对话回忆相关学习经历，并依据学生所处阶段、已学内容和偏好在不同对话中保持连贯。若把所有历史消息直接注入每次请求，上下文成本、延迟、无关信息和旧信息覆盖新信息都会失控；若只维护一段由模型自由改写的全局总结，又无法解释某项判断来自哪里，也无法可靠纠正误判。

原始对话、截图和附件已经是可保存的事实记录；学生画像则是从这些记录中提炼、会持续变化且影响未来回答的判断。两者生命周期不同，不能在同一个可变摘要中混用。

## Decision

We will 把持久学习记忆拆为两层：证据层自动保存可追溯的原始对话、截图与附件，并包含全局学习记忆入口自身的聊天与记忆篇章；这些记录默认纳入本地检索索引，但允许逐项关闭“用于全局记忆”。画像层只保存精简、可解释、可修改的学生信息与学习状态，并记录来源与置信度；画像采用全局基础信息加科目/领域分画像，不跨领域推断掌握程度。画像冲突按“用户明确纠正优先于近期直接学习证据，近期直接证据优先于旧推断”的顺序处理；单次表现只能形成候选更新，被替换的画像标记为过期而不是静默删除。全局学习记忆入口每次只把相关证据和当前有效画像组装进上下文，检索精度优先于召回数量，不把全部历史直接注入模型，也不维护不可审计的单一全局总结。

## Consequences

- 正面：Deriva 可以引用具体旧对话解释“为什么记得”，并在旧证据与画像冲突时回到来源纠正。
- 正面：模型每次只接收当前问题相关的片段，成本、延迟和上下文噪声可控。
- 正面：年级、已掌握/未掌握、性格与偏好等长期结论可以由用户查看、修改和删除，避免一次提问被永久误判为能力。
- 正面：全局入口可以记得自己的篇章与科目对话，同时科目/领域分画像避免把数学能力错误迁移到算法、语言或其他领域。
- 负面：数据模型需要同时维护证据索引与画像记录，删除对话时还要同步清理派生来源和处理失效引用。
- 负面：默认索引降低使用摩擦，但要求每段对话都能明确退出全局记忆，并在检索到附件时提供来源与控制入口。
- 负面：精度优先会接受一部分漏召回，并需要通过用户主动扩大搜索或改进索引来弥补。
- 负面：回答前增加检索与画像筛选步骤，需要分别测量召回质量、延迟和 token 成本。
- 中性：具体检索方式、画像字段和确认界面尚未由此 ADR 决定。

## Alternatives Considered

* 把全部历史消息注入每次请求 — 成本、延迟和噪声随记录增长不可控，旧信息也可能压过当前状态。
* 只维护一段自动改写的全局总结 — 无法追溯依据、纠正误判或判断信息是否过期。
* 继续只读取当前对话及祖先链 — 无法实现跨主对话与跨学习会话的记忆，新的全局学习记忆入口失去核心价值。
