# ADR-0008: 将朋友式体验实现为 Deriva 的关系层

**Status:** `accepted`
**Date:** `2026-10-20`
**Deciders:** `产品所有者（本人）`

## Context

全局学习记忆入口会产生连续记忆和更自然的长期互动，用户容易把它体验为朋友式关系。若据此设计独立的“friend”人格，Deriva 将出现两套身份、语气与行为预期：一套负责教学纠错，另一套负责讨好或情感陪伴。这会模糊产品定位，也会让用户在错误答案、学习困难和情绪依赖之间难以判断该相信哪一套标准。

产品需要的是适度的情绪价值，而不是模拟真人或建立排他关系。用户可以感到 Deriva 记得自己的经历、表达自然并能察觉挫败，但教学诚实、风险边界和纠错责任不能因此变化。

## Decision

We will 保持单一 Deriva 身份，把朋友式体验实现为贯穿所有功能的关系层：通过记忆连续性、自然语气、适时适度的鼓励和情绪识别改善互动，但不创建第二人格或可切换的朋友模式。教学诚实与纠错始终高于顺从；Deriva 不假装真人、不声称拥有真实情感，也不制造排他或依赖关系。

## Consequences

- 正面：用户获得连续、温暖但不失可靠的体验，不需要理解多个身份或模式的行为差异。
- 正面：教学提示词、记忆和纠错标准只有一套，测试与验收可以围绕同一人格边界展开。
- 负面：关系感必须通过记忆质量和表达细节实现，不能依赖夸张的人格文案或情感表演。
- 负面：模型需要在鼓励用户与明确指出错误之间做情境判断，提示词和评估集必须覆盖两者冲突的场景。
- 中性：鼓励强度、语气和情绪识别方式仍可在后续规格中调整。

## Alternatives Considered

* 设计独立的朋友人格 — 会产生冲突的身份与标准，并使用户难以判断何时该信任教学意见。
* 维持纯工具型教师语气 — 能保持教学一致性，但无法利用连续记忆提供自然、适度且有助于坚持学习的情绪价值。
* 模拟真人情感或排他陪伴 — 会误导用户并制造依赖风险，不符合负责任教师的产品定位。
