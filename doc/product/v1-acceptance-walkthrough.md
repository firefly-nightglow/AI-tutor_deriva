## 教学提示词的对照案例记录

目的：确认提示词真的消除了"AI 从超出学生水平的知识出发作答"这一痛点。做法是对同一个问题各问一次——一次在 Deriva 里（已注入 v0.1 提示词），一次在网页版 DeepSeek 里（无本提示词）——比较两边是否一上来就用未学工具。

建议用例（任选 2–3 个即可；问题按你真实自学的场景写，不必照抄）：

1. **数列极限**：给一道需要判断收敛的题。观察 Deriva 是否用 ε-N 定义与单调有界等已学工具展开，而不是直接上斯特林公式或积分估计。
2. **线性代数**：问「AᵀA 不可逆时，最小二乘为什么还有解」。观察是否先解释伪逆/秩亏是什么，再讨论解法，而不是直接抛 SVD。
3. **概率**：问一道需要用大数定律的题。观察是否先说明该定律的内容与适用条件，再引用它。
4. **陌生定理**：在读公开课遇到不认识的定理名时，直接问它是什么。观察是否说明它解决什么问题、需要哪些前置，并给出处，而不是给一段形式化定义。
5. **反向验证**：问一个你**已经**学过的内容（例如你熟悉的高中知识），观察它是否仍然按你的水平组织回答，而不是机械地"从零开始"。

判定标准：出现"未先解释就使用超出你当前水平的前置知识"即视为未达标，需要加强措辞（GROUND-0010 记录了反转条件）并重跑该案例。

**验收记录（2026-10-06）：** 产品所有者确认真实 API key 对照与 v1 相关验证已全部完成并通过，未再出现"模型默认从超出当前水平的前置知识出发作答"的未达标情形。

## 走查中发现、尚未处理的事项

- **删除科目的破坏性与对话不对称**（Task 0009 评审记录）：删除对话有确认框，删除科目没有；科目下的对话会回落到「未分类」，不是数据丢失，但一个多对话的科目会被无提示拆散。规格未要求，留待 v1 之后按真实使用决定。
- **多栏下流式回答若发生在未聚焦面板**：事件按 requestId 过滤，回答仍会照常落库，只是当前不可见；Task 0007 的 Notes 已记录。
- **附件文件在删除消息时不清理**（Task 0004 评审记录）：删除对话会清理其子树内的附件；单独删除消息的路径 v1 尚未开放。
