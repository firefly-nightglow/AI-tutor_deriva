# Deriva Desktop Release

本次交付把树状学习问答与当前阅读资料放到同一工作区，减少自学过程中的应用切换。

## Delivered

- 截图提问：屏幕/窗口来源、区域框选、放大确认、图像 API、历史缩略图与可选原图。
- 悬浮抽屉：左右全高贴边、气泡、托盘、全局热键、单实例和重启恢复。
- 内嵌资料：网页、视频站点、PDF、Markdown、文本和面板内截图。
- 外部并排：一个原生应用与抽屉共享工作区、边界调整、暂停及还原、异常恢复记录。
- 响应性：窗口控制在 utility process 执行；拖动条全高、44 DIP 热区、握柄居中。

## Validation

产品所有者确认功能验收、流式输出和最后一轮边缘拖动手感。自动测试 54 文件 292 项通过，类型检查和构建通过。隔离 Electron 驱动验证左右共十次指针拖动持续 active，并覆盖收起、展开与还原。不同系统及目标应用仍可能受权限、最小尺寸、网页 DRM 或登录策略限制。

## Data

发行包仅包含应用构建及运行依赖，不包含本机数据库、API Key、日志、截图参考或实测记录。截图提问会通过用户配置的模型 API 发送选定图片。

## Next

v3 先明确第一阶段学习会话的最小闭环：开始/暂停/结束、来源与同意边界、纪要式总结。屏幕与音频保留为独立来源，先做哪条由第一阶段规格确认。随后运行实现基础调研并拆任务；第二阶段使用已接受的全局学习记忆规格，不提前实现。
