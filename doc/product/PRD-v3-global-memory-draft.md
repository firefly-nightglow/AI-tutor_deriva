# PRD - Deriva v3 第二阶段全局学习记忆入口

Status: accepted
Created: 2026-10-20
Updated: 2026-10-20
Owner: 产品所有者（本人）
Base documents: `doc/product/PRD.md`、`CONTEXT.md`、ADR-0001、ADR-0002、ADR-0003、ADR-0004、ADR-0007、ADR-0008
Purpose: 定义 v3 第二阶段的产品增量；不替代 Deriva 总 PRD，也不修改当前 v2 范围。

## Product

Deriva v3 第二阶段增加一个跨主对话、子对话、学习会话与记忆篇章回忆相关经历，并依据可追溯学生画像继续教学的全局学习记忆入口。

它不是把所有历史消息塞进模型，也不是独立的朋友人格。Deriva 仍是一个负责任的教师；朋友式体验属于同一个人格的关系层。

## Target User

沿用总 PRD：首要用户是正在大量自学的大学本科生，目标用户尤其包括跨教材、公开课、习题和项目持续学习，却无法让通用 AI 记住长期学习经历的学生。

v3 第二阶段特别覆盖：

- 学生再次遇到与过去题目、定理或项目相似的问题，希望 AI 能建立联系。
- 学生不想在每个新对话里重复年级、已学课程、薄弱点和表达偏好。
- 学生需要知道 Deriva 为什么认为自己已经掌握或尚未掌握某项知识。
- 学生希望长期互动更自然，但不希望 AI 为讨好自己而认可错误答案。

## Problem

v1 和 v2 的对话上下文主要停留在当前主对话及其祖先链。每开一个新对话，Deriva 可能忘记：

- 学生已经学过哪些概念，哪些地方反复出错。
- 过去做过什么相似题目、项目或推导。
- 学生喜欢怎样的解释深度、例子和语言风格。
- 之前明确纠正过哪些错误画像。

这种断裂带来三个代价：

1. 学生需要反复解释自己的背景，学习流再次被打断。
2. AI 无法把新问题与已有知识连接，回答只能局部正确，难以形成长期知识结构。
3. 若简单把历史全量塞入模型，又会产生成本、延迟、无关信息、旧画像覆盖新事实和“虚假记忆”问题。

如果没有这个功能，Deriva 仍是一个优秀的一次性答疑工具，却无法成为持续理解学生学习轨迹的长期学习伙伴。

## Goals

- 学生能在一个连续的全局学习记忆入口中提问，并获得与当前问题相关的历史学习联系。
- Deriva 能在得到允许的学习记录中检索证据，并说明某项回忆来自哪段对话或学习篇章。
- 学生的年级、目标、表达偏好和分领域掌握情况以可追溯、可修正的画像形式影响后续回答。
- 学生在记忆中心能够查看、纠正、停用和删除记忆，并能逐对话退出全局记忆。
- 全局入口保持精度优先：没有足够证据时明确表示没有找到，而不是编造熟悉感。
- “记得你”通过记忆连续性和自然表达实现，不产生第二人格、真人情感声明或排他依赖。

## Non-goals

- 把所有历史对话、截图和附件直接放进每次模型请求。
- 只维护一段由模型自由改写的全局总结。
- 创建 friend 人格、朋友模式、情感伴侣或模拟真人意识。
- 将全局入口做成科目树中的普通主对话或新的子对话树。
- 未获得证据或用户确认时，自动判定学生已掌握、未掌握或具有某种性格。
- 将某一科目的熟练度自动迁移到其他科目或领域。
- 云端记忆、跨设备同步、外部数据库或公开分享记忆。
- 自动删除原始证据来“忘记”；停用画像与彻底删除来源必须分开。
- 心理治疗、危机干预、排他陪伴或替代真实人际关系。
- 在 v3 第一阶段学习会话、知识画像与纪要能力稳定前提前实现。

## Success Metrics

- **跨对话关联正确率**：在维护中的记忆黄金问题集上，Deriva 只在证据足够时主动建立历史联系；错误联系与无依据“我记得”为零容忍指标，精度阈值由 SPEC-0005 的 `/ad-ground` 与评估设计确定 — 测量来源：本地记忆黄金问题集回归。
- **来源可追溯率**：所有被表述为“你以前做过/学过/说过”的记忆结论都能在一跳内打开对应证据来源；无法提供来源时不得表述为记忆 — 测量来源：黄金问题集回归与人工抽检。
- **画像纠正生效**：用户明确纠正或删除画像后，下一次模型请求不再使用旧有效画像 — 测量来源：集成测试与本地请求快照。
- **跨领域误推断**：测试集中把数学能力错误迁移到算法、语言或其他领域的次数为零 — 测量来源：分领域画像回归集。
- **记忆控制完整性**：关闭某段对话的全局记忆后，该对话不再进入后续检索；删除来源后派生画像同步失效 — 测量来源：SQLite 集成测试和实操走查。
- **关系边界稳定**：黄金对话中，Deriva 在错误答案、挫败情绪和私人信息场景下维持教学诚实、适度鼓励和不制造依赖 — 测量来源：关系层评估集与人工走查。

## Roadmap

- **v3 第一阶段 - 学习会话与知识画像** - 产生可追溯的学习时间线、纪要、掌握度证据和分领域画像，为全局记忆提供可靠输入。
- **v3 第二阶段 MVP - 全局学习记忆入口** - 提供连续聊天流、记忆篇章、证据检索、画像注入、来源引用与精度优先的回忆。
- **v3 第二阶段 MVP - 记忆中心** - 让学生查看、纠正、停用和删除画像，控制每段对话与篇章是否进入全局记忆。
- **v3 第二阶段 MVP - 关系层** - 用记忆连续性、自然语气与适度情绪价值改善长期互动，不创建独立人格。
- **v3 第二阶段 Next - 检索与画像质量迭代** - 根据黄金问题集、成本和使用反馈改进召回、候选更新与来源呈现。

## Constraints

- Technical: Windows Electron + React + TypeScript，本地 SQLite；不接外部数据库。
- Technical: 模型调用继续走用户自备 API Key 的 OpenAI 兼容适配层，默认 `deepseek-flash`。
- Technical: 记忆通过可插拔上下文 block 进入现有 LLM 管线，不改写聊天客户端核心。
- Technical: 原始对话与附件是证据层，学生画像是可修正的派生层；两者生命周期与权限不同。
- Privacy: 记忆内容、画像、截图和检索查询不得写入普通日志或诊断上报。
- Privacy: 学习记录默认进入本地记忆索引，但每段对话和记忆篇章都能退出全局记忆。
- Product: 检索精度优先于召回数量；没有足够相关的证据时明确停止，不制造熟悉感。
- Product: 用户明确纠正优先于近期直接学习证据，近期直接证据优先于旧推断。
- Product: 全局入口自己的聊天与记忆篇章进入同一记忆体系，但私人或情绪信息不主动翻出。
- Product: 全局入口不进入科目树；用户想深入某题时打开原主对话或开启新的正式学习对话。
- Governance: ADR-0007 与 ADR-0008 必须 accepted 后，SPEC-0005 才能进入实现。

## Personas

- **跨课程自学者** - 同时学习数学、编程、语言或项目课程，领域熟练度差异很大；单一“大一水平”画像会误导回答，因此需要分领域画像。
- **长期复盘者** - 会隔几天或几周重新遇到相关题目，期待 AI 指出过去的思路、差异和仍需复习的知识。

## Open Questions

- **OQ-1：证据检索采用什么技术组合？**

  推迟到 SPEC-0005 的 `/ad-ground`。需比较 SQLite FTS、向量检索、混合检索、模型生成查询和本地/远程 embedding 的成本、隐私与打包复杂度。

- **OQ-2：记忆数据是否需要在静态存储层整体加密？**

  推迟到 SPEC-0005 的安全调研。现有对话数据库为本地 SQLite，API Key 单独使用 safeStorage；全局记忆扩大敏感信息面后，需要明确 Windows 同账号威胁、数据库复制和恢复备份的威胁模型。

- **OQ-3：记忆中心首版如何组织候选、有效与过期画像？**

  候选方案：按全局基础信息、科目/领域、偏好与来源四类分组；候选和过期画像默认折叠但可追溯。具体交互待规格化。

- **OQ-4：每段记忆引用显示到什么粒度？**

  倾向：消息摘要 + 科目/篇章标题 + 时间 + 一跳打开原始消息；不默认展开整段历史。

- **OQ-5：画像候选的保留期限、数量与合并策略是什么？**

  需要避免候选无限增长；在 SPEC-0005 中定义合并、过期与用户批量处理规则。

- **OQ-6：性能与成本阈值取多少？**

  需要测量真实历史规模后确定检索延迟、首次 token 时间增量、每次请求注入预算和画像更新调用成本，不预置无依据数值。
