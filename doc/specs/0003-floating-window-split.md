# Spec 0003: 悬浮窗、快捷入口与窗口级分屏（Floating Window And Split View）

**Status:** `accepted`
**Created:** `2026-10-06`
**Updated:** `2026-10-19`
**Owner:** `产品所有者（本人）`

## Context

Deriva 的核心价值是让学习提问不打断阅读。v1.0.0 已在普通窗口中交付树状对话，但用户在学习资料与 Deriva 之间仍需手动切换窗口；ADR-0003 曾把悬浮窗列入 v1 范围，实际未随 v1.0.0 交付。v2 已决定补齐完整悬浮窗，并把用户最初提出的“一边看 AI 输出的内容一边读分屏出来的文献、代码、网页、视频”落实为 Deriva 内嵌资料面板 + AI 对话面板的窗口级分屏。

本功能为 SPEC-0002 的屏幕提问提供随手可达的入口，也让用户在普通窗口、全高悬浮抽屉和分屏学习布局之间切换。若本功能不交付，屏幕感知仍要求用户频繁切换焦点，产品无法真正解决“查资料打断学习流”的痛点。

术语沿用 CONTEXT.md：主对话、子对话、科目；SPEC-0002 的屏幕片段、屏幕区域、屏幕提问。

## Amendment 2026-10-18 — 全高抽屉与可召回性

Task 0017 首轮实机验收暴露了四个产品形态问题：悬浮窗仍是一个 440×660 的小浮窗；切到悬浮模式后任务栏图标消失，最小化后没有任何可靠召回入口；窄窗口里树状侧栏挤占对话区；收起后的形态不是一个可识别的快捷入口。产品所有者与实现方逐项讨论后，确定本规格的悬浮窗采用“全高抽屉 + 快捷气泡 + 常驻托盘”的形态，并明确以下边界：

1. 悬浮模式是贴左/右边缘、高度等于显示器工作区的**悬浮抽屉**，不是可自由摆放的小浮窗；顶部/底部吸附移除。
2. 收起是隐藏抽屉并显示**快捷气泡**；最小化是 Windows 常规最小化，任务栏保留入口；关闭才真正退出。
3. 悬浮模式侧栏默认收起并以浮层出现；多对话面板在悬浮模式纵向堆叠，普通模式保持横向并排。
4. 内嵌资料面板在悬浮模式可用，默认关闭，资料在上、对话在下；普通模式保持左右分屏。
5. 重启恢复上次模式、边缘与宽度，但启动时总是展开；不恢复“气泡中”这个瞬时状态。
6. 外部应用并排不属于本规格，由 SPEC-0004 单独规定；本规格只负责抽屉自身的几何与召回可靠性。

## User Scenarios

- **Scenario 1:** 从普通窗口切换到全高悬浮抽屉
  - Given Deriva 正在普通窗口模式运行
  - When 用户切换到悬浮模式
  - Then Deriva 变成贴当前显示器左/右边缘、高度等于工作区的抽屉；用户可拖动内侧边界调整宽度，并继续当前对话

- **Scenario 2:** 快捷入口唤起 Deriva
  - Given 用户正在其他学习资料窗口中阅读
  - When 用户使用全局热键、任务栏入口、托盘图标、快捷气泡或再次启动 Deriva
  - Then Deriva 展开抽屉、获得焦点并恢复上次所在的主对话或新建提问入口，用户可立即输入问题或发起 SPEC-0002 的截图提问

- **Scenario 3:** 内嵌资料与 AI 对话窗口级分屏
  - Given 用户需要同时阅读文献、代码、网页或视频，并查看 AI 输出
  - When 用户打开资料面板
  - Then 普通窗口以左右分屏显示资料面板与 AI 对话面板；悬浮抽屉以纵向堆叠显示资料在上、对话在下。两侧均可独立滚动、调整比例、打开/关闭，并继续树状问答

- **Scenario 4:** 分屏中发起截图提问
  - Given 用户正在分屏布局中查看资料面板
  - When 用户对资料面板中的公式、代码或网页内容发起截图提问
  - Then SPEC-0002 的屏幕片段预览与提问流程在 Deriva 内完成，不打断另一侧资料面板

- **Scenario 5:** 恢复与降级
  - Given 用户重启应用、移动窗口到不存在的显示器、外部网页无法加载或视频无法在内嵌面板播放
  - When 应用恢复窗口布局或遇到加载失败
  - Then 应用恢复到合法显示器上的上次模式并展开抽屉；若状态非法则回到普通窗口。资料面板显示可理解的失败与重试入口，对话数据不丢失

- **Scenario 6:** 收起、最小化与召回
  - Given Deriva 正在悬浮模式运行，或已经被收起/最小化
  - When 用户分别点击“收起”“最小化”、任务栏图标、托盘图标、气泡或再次启动应用
  - Then “收起”隐藏抽屉并显示气泡；“最小化”保留任务栏入口；托盘始终可用；再次启动只会恢复当前实例，不会产生第二个进程

## Requirements

### Functional

- FR-1: Deriva 支持普通窗口模式与悬浮模式切换。悬浮模式的全高抽屉贴当前显示器工作区的左边缘或右边缘，高度等于工作区高度（不含任务栏），默认右侧；默认宽度 440px，内侧边界可在 360–720px 之间拖动调整；顶部/底部吸附与自由悬浮位置不属于本规格。
- FR-2: 用户可配置并触发至少一种快捷入口；快捷入口包括全局热键、任务栏入口、常驻托盘图标和收起后的快捷气泡。全局热键冲突或注册失败时必须提示并允许改键；再次启动 Deriva 必须恢复并聚焦当前实例，而不是创建第二个实例。
- FR-3: 悬浮模式与普通窗口共用同一套对话数据、设置与当前主对话状态；模式切换不得重置未发送草稿、当前主对话、已打开面板或正在流式生成的回答。悬浮模式的侧栏默认收起并以浮层出现，选择对话后自动收回；普通模式保持常驻侧栏。
- FR-4: Deriva 提供窗口级分屏布局：普通窗口默认左右分屏（一侧资料面板、一侧 AI 对话面板）；悬浮抽屉默认关闭资料面板，打开后纵向堆叠（资料在上、对话在下）。两种布局两侧均可独立滚动，比例可拖拽调整。
- FR-5: 资料面板至少支持打开网页 URL；本地文献、代码和视频支持方式在 `/ad-ground` 阶段比较 Electron 能力后确定，但规格要求失败后不得影响对话面板。
- FR-6: 分屏布局与 SPEC-0002 的屏幕提问入口集成；Deriva 资料面板作为内部捕获来源，用户可对其整幅捕获或局部框选提问。内部来源使用内部渲染捕获后端（`webContents.capturePage` / `WebContentsView.capturePage`），不隐藏 Deriva、不依赖 `desktopCapturer`。
- FR-7: 应用保存最近一次窗口模式、吸附边缘、抽屉宽度、分屏开关和面板比例；重启后恢复上次模式、边缘和宽度，但启动时总是展开抽屉，不恢复气泡态。资料面板每次打开均为空，关闭重开或重启后不恢复上次资料、地址输入和资料列表，资料仅在本次打开期间保留。显示器消失、状态非法或窗口越界时回退到合法显示器上的普通窗口。
- FR-8: 外部网页仅允许在受控资料面板中加载；外部链接按现有策略交给系统浏览器，不允许在面板内无提示跳转。
- FR-9: 悬浮模式、普通窗口和分屏模式均保留 SPEC-0001 的树状侧栏、书签、链路图、多面板、删除确认和设置入口。悬浮模式的多个对话面板纵向堆叠，普通模式横向并排；空间不足时允许折叠或提示关闭面板，但不丢失功能入口。
- FR-10: 当资料面板无法加载网页、文献、代码或视频时，显示失败原因、重试和关闭入口；对话面板保持可用。
- FR-11: “收起”隐藏抽屉并显示快捷气泡；“最小化”执行 Windows 常规最小化并保留任务栏入口；关闭窗口真正退出应用。托盘图标在普通、悬浮、最小化和收起状态下均可用。
- FR-12: 快捷气泡是独立的置顶小窗口，尺寸 56–64px，贴抽屉所在边缘，可沿边缘上下拖动并记住位置；单击展开抽屉，右键菜单至少提供“打开 Deriva / 设置 / 退出”。抽屉展开时气泡隐藏。
- FR-13: 外部应用并排（选择一个外部应用与 Deriva 共享工作区、调整边界、暂停/还原）不属于本规格，由 SPEC-0004 单独规定。

### Non-functional

- NFR-1: 窗口模式切换、分屏开关、抽屉展开/收起和宽度拖动在普通笔记本上保持可响应，不阻塞正在进行的流式回答。宽度拖动期间用动画帧合并布局更新，松手后再持久化状态，避免逐像素写盘和重复重排。
- NFR-2: 全局热键只在用户显式启用后注册；应用退出时注销，不遗留系统级快捷键。
- NFR-3: 内嵌资料面板遵循现有安全边界：禁用未经类型安全桥接的 Node 能力，外部内容不得访问本地文件或 IPC。
- NFR-4: 窗口状态、布局比例与吸附位置保存在本地配置中，不写入日志，不上传。
- NFR-5: 触控适配：抽屉内侧宽度拖动条、跨显示器拖动、分屏比例调整、气泡、关闭/展开控件在 Windows 触屏设备上可用，点击热区不小于 44px。
- NFR-6: 高分辨率与多显示器环境：悬浮窗不得恢复到屏幕外；窗口缩放比例变化后仍保持可用布局。
- NFR-7: 托盘、气泡与主抽屉的生命周期彼此隔离；任一窗口隐藏、最小化或重建都不得导致应用失去唯一可用的召回入口，也不得留下无法关闭的孤儿窗口。
- NFR-8: 单实例锁在应用启动早期获取；第二次启动通过进程间唤醒恢复现有实例。若主窗口已销毁但进程仍存活，必须重建主窗口并恢复合法布局。

## Success Criteria

- 用户能在普通窗口与全高悬浮抽屉之间切换，抽屉贴左/右边缘、铺满工作区高度，宽度可在 360–720px 内调整并记忆。
- 用户能通过全局热键、任务栏、托盘、气泡或再次启动唤起 Deriva；“收起”显示气泡，“最小化”保留任务栏入口，关闭才退出。
- 用户能在普通窗口中左右并排阅读资料面板与对话，在悬浮抽屉中上下堆叠资料与对话，并分别调整比例和独立滚动。
- 分屏布局中可完成一次基于资料内容的截图提问，回答进入同一树状对话且重启后可恢复。
- 重启后恢复上次模式、边缘和宽度并展开抽屉；资料面板加载失败、显示器移除或窗口越界时，应用自动回到合法布局，对话数据不丢。
- SPEC-0001 的树状对话功能在普通窗口、悬浮抽屉与分屏模式下均可用；悬浮模式多对话纵向堆叠，普通模式横向并排；触控关键控件满足 44px 热区。

## Edge Cases

- 全局热键被系统或其他应用占用、用户按下重复热键、应用启动时热键注册失败。
- 多显示器断开、分辨率或缩放比例变化，导致上次抽屉边缘、宽度或分屏尺寸不可用。
- 抽屉被拖拽到另一显示器、贴近任务栏、覆盖全屏应用，或目标显示器工作区窄于 360px。
- 用户在收起、最小化、流式回答进行中或资料面板加载失败时再次启动 Deriva；必须恢复同一个实例而不是新建进程。
- 资源管理器重启、托盘图标暂时消失、气泡被拖到屏幕外或用户误关闭气泡；任务栏、托盘、热键与再次启动至少保留一条可用召回路径。
- 悬浮模式侧栏浮层打开时用户点击收起或切换模式；先关闭浮层，再执行收起/切换，不留下遮罩或不可点击区域。
- 资料面板中的网页要求登录、拦截嵌入、使用第三方 Cookie、播放 DRM 视频或跳转到外部链接。
- 悬浮抽屉中纵向打开多个对话面板与资料面板，垂直空间不足；提示用户关闭面板，不把内容压到不可用高度。
- 流式回答期间切换窗口模式、调整抽屉宽度、拖动分屏比例或收起抽屉；正在生成的消息不得丢失。
- 用户在资料面板中打开危险或不支持的协议；必须拒绝或交给系统浏览器处理。

## Out of Scope

- 后台持续屏幕读取、学习会话时间线、字幕提取与总结（v3）。
- 选择并控制用户已有的其他软件窗口自动并排；该能力由 SPEC-0004 单独规定，本规格只交付内嵌资料面板。
- 快捷气泡自动贴边隐藏、顶部/底部抽屉吸附、自由悬浮摆放。
- SPEC-0002 的截图捕获、隐私排除、附件保存与视觉上下文注入细节。
- Android / iPad 悬浮窗、浏览器插件或系统级 always-on-top 插件市场。
- 云端窗口布局同步、多设备布局恢复。

## Open Questions

### Amendment 2026-10-16 — 资料面板作为内部捕获来源

产品所有者确认 SPEC-0003 的分屏资料面板必须能被截图提问，而不是只能截取面板背后或旁边的外部屏幕内容。该需求不改变 SPEC-0003 的功能边界：仍然是“内嵌资料面板 + AI 对话面板”的分屏学习，只是明确其截图路径使用内部渲染捕获后端。内部来源与外部来源共享同一套来源选择、预览确认、附件和树状对话流程，具体来源描述与后端选择见 ADR-0005。

- OQ-1: 资料面板对本地 PDF、代码文件与视频的支持优先级如何排序？

  决议（2026-10-06）：规格只要求“至少网页 URL + 失败降级”；具体支持矩阵在 `/ad-ground` 阶段比较 Electron 能力与实现成本后确定。
- OQ-2: 悬浮窗收起后的视觉形态是细条、圆形按钮还是带标题的窄面板？

  决议（2026-10-18）：采用独立圆形快捷气泡（56–64px），贴抽屉所在边缘、可沿边缘上下拖动、常显；抽屉展开时气泡隐藏。自动贴边隐藏不在 v2 范围内。
- OQ-3: 全局热键默认值选什么？

  决议（2026-10-06）：不预置默认值；实现时在 `/ad-ground` 阶段检查常见 Windows 冲突后确定，并提供改键。
