## Resolution log (post-review, same turn)

- Standards Concern 1 (a selected node can stay hidden behind a collapsed ancestor) — fixed: added the
  pure helpers `ancestorIds(all, id)` and `expandCollapsed(current, ids)`, and App now expands the
  selected node's ancestor chain whenever the selection changes. Covered by a chain-walking test and an
  expand/no-op test.
- Standards Note 2 (inconsistent storage accessor) — resolved by routing collapse persistence through
  the same `saveCollapsed(browserStorage(), ...)` call used by the other UI preferences; the theme
  still reads `window.localStorage` directly at first render because it must apply before paint.
- Standards Notes 3–6 — recorded, no action in this task: stale ids in the collapsed set are a few
  bytes each and can be pruned when the delete flow is revisited (Task 0009); the toggle's 20×24 hit
  area is below the 44 px touch guidance but NFR-5 names only the ask entry and panel close control;
  flat grouping would hide a child whose parent is filtered out of the input list (unreachable while
  `listAll` returns everything); the seeder intentionally mirrors the insert shape as a one-off tool.

bundles.
