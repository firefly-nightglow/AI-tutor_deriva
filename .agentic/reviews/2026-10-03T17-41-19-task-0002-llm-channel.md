## Resolution log (post-review, same turn)

- Standards Concern 1 (streaming state from a ref) — fixed: `App.tsx` now holds `streaming` in state,
  sets it true when a request starts and false when a terminal event arrives, so the composer unlocks
  on completion instead of waiting for an unrelated re-render.
- Standards Note 2 (`normalizeDisplayMath` could span lines) — fixed: the inner group is restricted to
  `[^\n]`, with a test asserting two adjacent display lines stay separate.
- Standards Note 3 (unhandled rejection in `cancel`/`retry`) — fixed with try/catch in both handlers.
- Standards Note 4 (implicit thinking mode and no `max_tokens`) — carried into the Task 0003 Notes; the
  conversation UI owns whether to expose a thinking toggle, and Task 0010 owns the prompt policy.
- Standards Note 5 (key-store unavailability reported as "no key") — carried into the Task 0003 Notes
  for the settings panel to disambiguate.
- Standards Note 6 (broadcast to every window) — carried into the Task 0003 Notes; becomes real when
  the floating window from SPEC-0002 exists.

Post-fix verification: 67 tests pass, `npm run typecheck` clean, `npm run build` produces all three
bundles with the KaTeX assets.
